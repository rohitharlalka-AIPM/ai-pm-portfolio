token: a token is the basic unit used by LLM models to classify the length of input and output. Also, the billing for LLM use is based on no. of token used (input//output/cached)
context window: contect window is the limit for length of historic input/output tokens used by LLM for generating the response 
embedding: is the numeric number assigned to the embedded data in vector DB
RAG: reterival augmented generation is a technique used to enhance the output of LLM models by letting them retrieve required info form the vetor db to generate a response
function calling: used to execute a tool like calculator, web search etc for LLM agents
tool use: ability to use tools like calculator and web search by LLM agents
agent: a specific orchestration of rules to constraint LLM models to be expert in specific task
workflow: set of rules, using agent (s), to execute a pre-defined set of tasks
MCP: a protocol for AI Agents to interact with 3rd party application via APIs
eval: evalution metric to understand the performance of agentic AI products
hallucination: made-up output by LLM agents that is not grounded in known facts or informaction provided by the user
temperature: limits the creative output from LLM agents, 0 being least creative, 1 being most
top_p: set of related matches that LLM model can return from the semantic search
fine-tuning: custom training of the base LLM models using techniques like LoRA
prompt caching: a method to store the previous prompts so that the input token cost can be optimized
reasoning model: the LLM model like ChatGPT, CLaude
computer use: a skill that allows AI agents to use computer, like humand, for browsing, filling forms, etc.
guardrail: a set of symbolic rules to enforce or restrict LLM outputs
